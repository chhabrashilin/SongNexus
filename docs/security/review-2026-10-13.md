# Security review (M8-04)

Scope: the `v2` branch as of 2026-10-13: API, identity, importers, web client, hosting configuration, supply chain.
Method: STRIDE walk (plan §19) against the code and tests, plus new automated checks. This is not an external
penetration test.

## Results by threat

| Threat | Control | Evidence | Status |
|---|---|---|---|
| Forged ID token | signature, audience, issuer, expiry via Firebase Admin; unconfirmed age rejected | `test_sign_in_rejects_bad_tokens_wrong_origins_and_unconfirmed_age` | Pass |
| Session theft or fixation | opaque random session, only a hash stored, `HttpOnly; Secure; SameSite=Lax`, host-only `__session`; revoke-all | `test_sign_in_sets_a_hardened_cookie_and_stores_only_a_hash`, `test_sign_out_everywhere_revokes_other_devices` | Pass |
| CSRF | `X-CSRF-Token` plus Origin allow-list on every state change | `test_writes_require_the_csrf_token_and_an_allowed_origin` | Pass |
| IDOR | every user resource is checked against the session's user; anonymous gets 401 | `test_users_cannot_touch_each_others_data`, `test_anonymous_access_to_user_resources_is_unauthenticated` | Pass |
| Injection | SQLAlchemy parameters only; strict pydantic request models; one resource-name parser | code review; invalid-argument cases in `test_api.py` | Pass |
| Denial of service | 1 MB body limit, bounded query length, path depth and page size, per-class token-bucket rate limits keyed by user or address, bounded import size | `test_api.py` oversized-body test; load test (docs/perf) | Pass (limits are per instance) |
| Information disclosure | AIP-193 errors carry no stack traces; request bodies, cookies and tokens are not logged | log assertions in `test_api.py` | Pass |
| Account deletion and export | soft delete with 28-day purge job; export returns only the caller's data | `test_delete_account`, `test_export_contains_the_users_data` | Pass |
| Hostile import files | parsed on the device in a Worker; size limits (100 MB file, 500 MB total); ZIP entries filtered by name and size; dotfiles and `__MACOSX` skipped | **new** `web/src/importers/fuzz.test.ts`: mutation, noise, deep nesting, wide arrays, prototype pollution, ZIP bomb, path traversal | Pass, no finding |
| Browser injection | strict CSP with no inline scripts, `frame-ancestors 'none'`, HSTS, nosniff, referrer and permissions policies | **new** `web/e2e/csp.spec.ts` loads every route under the real policy and fails on any violation (mutation-checked) | Pass, no finding |
| Elevation via game | the puzzle is stateless and server-computed; progress is local and cosmetic; no badges exist yet | ADR 0004 | N/A until server game sessions exist |

## Supply chain

- `npm audit --omit=dev`: 0 vulnerabilities. `pip-audit` on the installed server environment: no known vulnerabilities.
- Open: `npm audit` reports advisories in dev-only `gts` dependencies (not shipped). Revisit when `gts` releases.
- Firebase pulls a vulnerable `@grpc/grpc-js`; it is overridden to a patched version (web/README.md).
- GitHub Actions are pinned by commit SHA; CodeQL, Dependabot and lockfiles are in place. SBOMs: [docs/sbom](../sbom/README.md).

## Findings and decisions

| # | Finding | Severity | Decision |
|---|---|---|---|
| S1 | The production CSP had never been exercised against the app (Firebase headers are not applied by `vite preview`). | Medium: it could have broken every page | Added `csp.spec.ts`; no violation found. |
| S2 | No fuzzing of importers existed. | Medium | Added `fuzz.test.ts` (300 seeded rounds per run; a 6,000-round run was clean). |
| S3 | Rate limits are per Cloud Run instance, not global. | Low | Accepted at demo scale (documented in `ratelimit.py`); a shared store is an R2 item. |
| S4 | The proxy hop count (`SONGNEXUS_TRUSTED_PROXY_HOPS`) is untested against real Cloud Run plus Hosting. | Medium | Verify on staging with a spoofed `X-Forwarded-For`; until then treat per-address limits as best effort. |
| S5 | No dedicated audit log of account changes (plan §19, repudiation). | Low | Deletion and sign-out appear in structured logs; an audit table is deferred. |
| S6 | No external penetration test and no IAM or secrets review (there is no GCP project yet). | n/a | Required before any launch beyond testers. |

No critical or high findings. S4 and S6 gate a wider launch.
