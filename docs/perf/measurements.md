# Performance measurements

Plan §23 budgets are proposals until measured. Actuals are recorded here; targets are never edited after the fact.
Measured on a developer laptop (Windows 11, Python 3.12, single process), reference catalog of 5,854 artists,
23,800 search keys. Staging numbers on Cloud Run (1 vCPU) are still to be taken (M8-01).

### Name matching: what was tried

| Change | 2,000 names | Search p95 | Kept |
|---|---|---|---|
| Baseline: one ranked search per name | 62 s | 71 ms | — |
| Edit-distance bound in pure Python | 93 s (worse) | 71 ms | No |
| Native edit distance (rapidfuzz OSA; verified equal to the reference on 1,000 cases) | 24 s | 18 ms | Yes |
| Trigram sets cached, partial ranking, type pre-filter | 24 s | 14 ms | Yes |
| Exhaustive filtered candidates at the review floor (0.69) | 110 s (worse: the q-gram bound is vacuous at 31% error) | — | No |
| Exhaustive filtered candidates at the decision floor (0.80) | 13 s | 14–19 ms | Yes |
| Prefix filtering on rare trigrams | 15 s (no gain: 89% of trigrams still probed) | — | No |

The kept design is exact for every matched/not-matched decision (property-tested against brute force); see
`SearchIndex.similar_docs` and `decisive_similarity`.

### Mitigations for the missed budget (in R1)
- Resolutions are cached per catalog version (`ResolutionCache`), so popular artists are matched once across users.
- History imports match the 500 most-listened artists, not every artist ever played.
- The UI shows progress; the request is a single call per playlist.

### Path to the target (R2)
Precompute resolutions for every catalog name and alias at ingest time (an exact-key lookup then decides most
real-world names in microseconds), and move fuzzy candidate generation to a native index. Re-measure on Cloud Run.

## Import match quality (AC-10.2)
Labeled set `data/eval/import_match_cases.json` (395 cases, generated by rules from human-verified seed IDs):
precision **0.993** (gate ≥ 0.98), recall 0.907. Homonyms auto-matched: 0 of 22. Both errors are labeled near
misses: "The Beetles" → The Beatles and "The Weekend" → The Weeknd, the inherent cost of typo tolerance.
